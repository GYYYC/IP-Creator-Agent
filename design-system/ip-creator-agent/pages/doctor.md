# Page Override: Doctor

## Page Goal

Diagnose why a piece of content performed the way it did and point to the next fix clearly.

## Key Feeling

- Clinical, but not cold
- Evidence-based
- Decisive

## Layout

- Top: mode switch for `图文 Graphic Post` and `视频 Video`
- Left: upload and evidence inputs
- Center: diagnosis report
- Right: key findings and next actions

## Rules

- For video mode, timeline alignment is the main visual centerpiece.
- Use highlighted drop-off markers tied to content moments.
- Keep the analysis readable in one screenful before deeper drill-down.
- Add a visible handoff path to `Assistant` for comment operations.
