# Page Override: Home

## Page Goal

Convince judges and first-time visitors that IP Creator Agent gives ordinary knowledge-first KOCs an MCN-level operating system.

## Hero Direction

- Use a large bilingual headline.
- Highlight the promise: one creator, four agents, one growth loop.
- Primary CTA: start building creator profile.
- Secondary CTA: try exam-coach demo.

## Recommended Hero Copy Direction

- Main statement should communicate:
  `让普通创作者也拥有 MCN 级内容运营团队`
- Support line should connect:
  `普惠 AI` + `低门槛创作` + `商业效率`

## Hero Visual

- Show a central AI workbench mockup.
- Surround it with four floating module cards:
  Profile, Director, Doctor, Assistant.
- Use blue and teal glow, with orange only for the key CTA.

## Section Structure

1. Hero
2. Why KOCs struggle today
3. Four-agent capabilities
4. Closed-loop workflow
5. Demo scenario for exam/study creators
6. Competition-value framing
7. Final CTA

## Home-Specific Rules

- The homepage should feel more cinematic than the internal app pages.
- Use larger glow fields and more atmospheric gradients here than elsewhere.
- Keep core text blocks short and judge-friendly.
