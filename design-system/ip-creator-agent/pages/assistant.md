# Page Override: Assistant

## Page Goal

Turn comments into reply strategy, emotion insight, and community guidance.

## Key Feeling

- Calm
- Smart
- Protective

## Layout

- Left: comment input zone for screenshot or pasted text
- Center: comment classification and reply drafts
- Right: operations strategy, pin recommendations, and risk notes

## Rules

- Support both screenshot upload and pasted text.
- Prioritize "high-value comments", "risky comments", and "worth pinning".
- Replies should sound like a creator coach, not a customer support bot.
