# Page Override: Director

## Page Goal

Help users turn a rough idea, fragment, or experience into a complete graphic-post draft or video script.

## Key Feeling

- Strategic
- Generative
- Guided

## Layout

- Left: input and guided questioning
- Center: generated script workspace
- Right: structure score, audience fit, publishing tips

## Rules

- User must choose `图文 Graphic Post` or `视频 Video` before generation.
- Follow-up questions should feel like a creator interview, not a form.
- Limit active follow-up rounds to a small number.
- Generated outputs should feel editable, not frozen.
